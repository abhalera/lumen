## Core Facts (text-verified)

| Item | Topic | Result |
|---|---|---|
| Testis | Size, cooling, compartments | 4–5 cm × 2–3 cm; scrotum 2–2.5°C lower; ~250 lobules × 1–3 tubules |
| Tubule | Lining + surroundings | Spermatogonia (meiotic) + Sertoli (nutrition); Leydig (androgens) outside |
| Ducts | Order | Rete testis → vasa efferentia → epididymis → vas deferens → ejaculatory duct → urethra → meatus |
| Plasma | Contents | Fructose, calcium, certain enzymes; bulbourethral lubrication; with sperms = semen |
| Ovary | Size, stroma | 2–4 cm; epithelium; cortex + medulla; ligaments |
| Tube | Length, parts | 10–12 cm; infundibulum (fimbriae) → ampulla → isthmus |
| Uterus | Layers, canal | Perimetrium + myometrium + endometrium; cervical canal + vagina = birth canal |
| Breast | Lobes, path | 15–20 lobes; alveoli → tubules → duct → ampulla → lactiferous duct → nipple |
| Sperm counts | Ploidy, ejaculate, cut-offs | 46 → 23 → 23; 200–300M per coitus; ≥60% normal form, ≥40% vigorous motility |
| Hormones | Spermatogenesis | GnRH → LH + FSH; LH → Leydig → androgens; FSH → Sertoli → spermiogenesis factors |
| Follicles | Reserve, series | Foetal millions → 60–80k per ovary at puberty; primary → secondary → tertiary (antrum) → Graafian + zona → ovulation |
| Cycle | Days, surge, fork | 28/29 days; flow 3–5; LH surge ~day 14 → ovulation; luteum → progesterone or degeneration; menopause ~50 |
| Zygote | Chromosomes, sex | 46 (23 + 23); ova all X, sperm 50/50 X/Y → XX female, XY male (father decides) |
| Embryo | Cleavage, layers | 2/4/8/16 → morula 8–16 → blastocyst (trophoblast + inner cell mass) → implantation |
| Placenta | Exchange, hormones | O2/nutrients in, CO2/waste out; hCG/hPL/estrogens/progestogens + later ovarian relaxin; trio pregnancy-only |
| Milestones | Clock | 1 mo heart → 2 mo limbs/digits → 12 wk systems → 5 mo movement/hair → ~24 wk fine hair/eyelids/eyelashes → 9 mo ready |
| Birth | Reflex, first milk | Foetal ejection reflex → pituitary oxytocin → stronger contractions → delivery + placental expulsion; colostrum antibodies, breast-feed initially |
